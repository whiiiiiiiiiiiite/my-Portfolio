校園活動管理系統

使用 Java 打造的主控台校園活動管理系統,支援活動建立、學生報名、名額管理與資料匯出,並以 CSV 作為輕量資料儲存方案。

角色
系統開發 / UI 互動
團隊
2 人小組
技術
Java・CSV 資料管理
類型
課程期末專題

1系統功能

系統以 Model / Service / Repository 分層設計,涵蓋學生功能、主辦方管理、使用者權限分級與資料查詢等模組。

  • 學生：瀏覽活動、報名 / 取消報名
  • 主辦方：建立活動、管理名額、查看報名名單
  • 系統：CSV 資料讀寫、報表匯出、資料驗證

2我的貢獻

主要負責 JavaFX UI 介面設計、事件處理與基本架構搭建,並協助排查互動測試中發現的邊界情況錯誤。

  • 設計主控台選單與使用者互動流程
  • 處理事件註冊、報名結果回饋等外部事件
  • 參與 UI 互動測試與 Bug 排除
