線上購物系統資料庫設計

一份完整的關聯式資料庫課程專題:從需求分析、ER Model 建模、正規化設計,到實際撰寫 SQL 查詢並用 EXPLAIN ANALYZE 驗證效能。

角色
資料庫設計 / SQL 撰寫
團隊
6 人小組
工具
PostgreSQL・draw.io
類型
課程期末專題

1專題目標

設計一套支援線上購物情境的關聯式資料庫,需涵蓋顧客、商品、供應商、訂單、庫存、交易與商品評論等完整業務流程,並確保資料一致性與查詢效能。

  • 完整的實體關聯(ER)建模與正規化設計
  • 10 張以上資料表,涵蓋多對多與弱實體關係
  • 撰寫商業情境查詢並分析執行計畫

2我的貢獻

負責資料表結構設計與多題複雜 SQL 查詢的撰寫,並針對效能瓶頸使用 EXPLAIN ANALYZE 找出可優化的查詢路徑。

  • 設計顧客、商品、訂單、交易等核心資料表 DDL
  • 撰寫跨表 JOIN、GROUP BY、HAVING 等進階查詢
  • 比對索引前後的查詢計畫,驗證效能改善
